# 소형 결정 모델 파인튜닝: Laya vs TypeSafe Jev

텍스트를 생성하지 않고 정해진 질문의 보기마다 확률을 돌려주는 "결정 모델"을 두 가지 공개 데이터로 비교했습니다.

- **Jev**(TypeSafe AI): 비공개 API이며 학습할 수 없습니다. zero-shot으로 판정했습니다.
- **Laya**(Convai Innovations, Apache-2.0): 오픈 가중치 모델입니다. RTX 5090 한 장에서 직접 파인튜닝했습니다.

두 모델은 같은 `POST /v1/systemone` 요청 형식을 쓰므로, 같은 질문과 같은 테스트셋을 그대로 보냈습니다. 평가 코드는 [`eval_cs_bitext.py`](../eval_cs_bitext.py)입니다.

## 결과 요약

| 실험 | 데이터 | Jev (zero-shot) | Laya 학습 전 | **Laya 학습 후** | 학습 비용 |
|---|---|---|---|---|---|
| 영어 CS 의도 분류 | Banking77, 77개 의도, 테스트 3,080건 | 정확도 79.4% | 36.3% | **90.4%** | 421M, 34분, GPU 9.5GB |
| 한국어 혐오 표현 판정 | K-MHaS, 다중 라벨 8개, 테스트 3,000건 | macro F1 0.517 | 0.207 | **0.733** | 322M, 2시간 42분, GPU 7.7GB |

학습한 Laya를 서빙할 때 GPU 메모리는 약 2~3GB이고, 요청 하나의 중앙 처리 시간은 0.16초였습니다(Jev API 0.19초).

## 1. Banking77 (영어, 은행 고객 문의 77개 의도)

- 평가: 공식 테스트셋 3,080건(의도당 40건). 보기는 라벨 이름의 `_`를 공백으로 바꾼 77개입니다.
- 학습: 공식 학습셋 10,003건(학습 9,603건, 확률 보정 400건), 4 에폭.

| 모델 | 정확도 | 8개 그룹 정확도 | 확신도 0.9 이상 비율 | 그 안의 오답률 |
|---|---|---|---|---|
| Jev | 79.4% | 92.3% | 64.6% | 6.4% |
| Laya 학습 전 | 36.3% | 56.8% | 48.0% | 38.6% |
| **Laya 학습 후** | **90.4%** | **96.2%** | **81.1%** | **3.3%** |

- 8개 그룹 정확도는 예측이 정답과 같은 처리 경로(카드 발급, 카드 문제, 결제 이상, 수수료·환율, 송금, 충전, 본인확인, 환불)에 들어가면 정답으로 셉니다.
- Jev가 크게 틀린 의도에서 차이가 컸습니다: `order_physical_card` 92% vs 8%, `topping_up_by_card` 78% vs 35%, `beneficiary_not_allowed` 78% vs 18%.
- 학습한 Laya는 확신도 0.9 이상으로 답한 비율이 높고 그 안의 오답률은 낮아서, "확신이 낮으면 상담원에게 넘기는" 구조에서 자동 처리량이 많습니다.

## 2. K-MHaS (한국어 뉴스 댓글 혐오 표현)

- 평가: 공식 테스트셋 21,939건 중 무작위 3,000건(원래 비율 유지). 카테고리 8개(출신, 외모, 정치, 욕설, 연령, 성별, 인종, 종교)마다 한국어 예/아니오 질문을 하나씩 두고, 한 요청에 8개를 묶었습니다. 확률 0.5 이상을 "예"로 판정했습니다.
- 학습: 공식 학습셋 78,977건 중 무작위 3만 건(질문 24만 개), 4 에폭.

| 모델 | macro F1 | 인종 제외 macro F1 | 혐오 여부 정확도 | 라벨 전체 일치율 |
|---|---|---|---|---|
| Jev | 0.517 | 0.545 | 79.1% | 51.3% |
| Laya 학습 전 | 0.207 | 0.236 | 65.7% | 36.1% |
| **Laya 학습 후** | **0.733** | **0.786** | **86.6%** | **79.4%** |

카테고리별 F1(Laya 학습 후 / Jev): 욕설 0.90 / 0.48, 연령 0.81 / 0.48, 출신 0.79 / 0.61, 정치 0.79 / 0.54, 종교 0.78 / 0.63, 외모 0.74 / 0.55, 성별 0.70 / 0.52.

- Jev는 재현율은 높지만 정밀도가 낮습니다. 욕설의 경우 실제 욕설의 81%를 찾지만, 욕설로 판정한 것 중 35%만 맞았습니다. 학습한 Laya는 같은 카테고리에서 정밀도 89%, 재현율 84%입니다.
- 인종은 평가셋에 7건뿐이어서 점수를 해석하지 않습니다.

### 오류 분석으로 질문 문구를 고친 과정

1만 건으로 먼저 학습한 모델(macro F1 0.645)의 오류를 유형별로 나눴습니다.

- 놓친 경우(322건)가 오탐(155건)보다 많았고, 은어·초성 약어·신조어 비하 표현에서 주로 놓쳤습니다.
- 종교나 정치를 "언급"만 한 댓글을 혐오로 판정하는 오탐이 있었습니다.
- K-MHaS는 성적 지향 비하를 "성별"로 분류하는데, 처음 질문에는 성별만 적혀 있어 성별 재현율이 51%에 그쳤습니다.

그래서 성별 질문에 "성적 지향"을, 인종 질문에 "백인, 흑인처럼"을 넣어 라벨 기준과 맞췄습니다. 문구만 바꿔도 Jev의 macro F1이 0.489에서 0.517로 올랐고, 바뀐 문구와 3만 건으로 다시 학습한 Laya는 0.733이 됐습니다. 1만 건과 3만 건 사이에는 학습량과 문구가 함께 바뀌었으므로 상승분을 둘 중 하나의 효과로 나눌 수 없습니다.

## 학습 설정

- 도구: `laya-train`(laya 0.4.31), 목적함수 RLCD(점수 규칙 기반 강화학습), micro-batch 8 × gradient accumulation 8, seed 42, 학습 후 온도 보정.
- Banking77은 보기가 77개라 Laya 기본 보기 영역(192토큰)에 다 들어가지 않습니다. 학습과 평가 모두 `max_len=1024`, `head_max_len=1024`로 맞췄습니다.
- 환경: Windows 11 + WSL2 Ubuntu, RTX 5090 32GB, PyTorch 2.11.0+cu128.

| 실험 | 학습 문항 | 최적화 횟수 | 에폭별 평균 loss | 소요 시간 | GPU |
|---|---|---|---|---|---|
| Banking77 | 9,603 | 604 | 1.062 / 0.666 / 0.792 / 0.900 | 34분 31초 | 약 9.5GB |
| K-MHaS 3만 건 | 239,600 | 14,976 | 0.662 / 0.450 / 0.333 / 0.238 | 2시간 41분 | 약 7.7GB |

RLCD는 스텝별 loss가 음수로 나오거나 크게 흔들리므로, 학습 성과는 테스트셋 지표로 판단했습니다.

## 재현

```bash
python eval_cs_bitext.py sample banking77          # 평가셋 만들기
python eval_cs_bitext.py trainset banking77        # laya-train용 JSONL
python eval_cs_bitext.py run banking77 laya-ft     # 서버(127.0.0.1:8898)에 판정 요청
python eval_cs_bitext.py report banking77 laya-ft
```

데이터는 `data/datasets/` 아래에 직접 받아야 합니다(Banking77: PolyAI, K-MHaS: adlnlp/K-MHaS). Jev를 쓰려면 `.env`에 `JEV_API_KEY`를 넣습니다.

## 한계

- Jev는 학습할 수 없어 zero-shot으로만 비교했습니다. Banking77에서는 Jev에 보기 설명 없이 라벨 이름만 줬습니다.
- 실험마다 학습을 한 번만 실행했습니다(seed 42). 반복 편차는 측정하지 않았습니다.
- 학습 데이터와 테스트 데이터가 같은 분포입니다. 다른 도메인이나 문체에서의 성능은 확인하지 않았습니다.
